🌦️ WEATHER PULSE – Interactive Weather Dashboard with Live Maps & AQI
------------------------------------------------------------------------------------
Live Demo: https://niaj-morshed.github.io/WEATHER-PULSE-Interactive-Weather-Dashboard-with-Live-Maps-AQI/


🚀 Overview:
-------------
Weather Pulse is a high-performance, real-time weather monitoring application. Built with a focus on data
accuracy and immersive UI, it integrates the OpenWeather API and Leaflet.js Maps to provide users with 
hyper-local weather updates, air quality insights, and a visual geographical experience.


✨ Key Features:
-----------------
1. 🌍 Interactive Live Maps (Leaflet.js)
    * Visual Tracking: Integrated interactive map to visualize weather conditions globally.
    * Click-to-Search: Explore weather data for any location by interacting with the map interface.

2. 🌫️ Air Quality Index (AQI) Insights
    * Health First: Provides real-time AQI levels to help users understand the air quality in their specific city.
    * Detailed Metrics: Tracks pollutants and provides an overall safety rating.

3. 🌡️ Comprehensive Weather Metrics
    * Real-time Data: Accurate display of Temperature, Humidity, Wind Speed, and Visibility.
    * 5-Day Forecast: Visualized 5-day weather trends to help users plan ahead.

4. ⭐ Favorites & Search History
    * Quick Access: Save your most-visited cities to a "Favorites" list using LocalStorage.
    * Smart Tracking: Automatically maintains a search history for faster navigation during future sessions.

5. 🌓 Dual Theme Experience (Dark/Light Mode)
    * Adaptive UI: Toggle between a cinematic midnight theme and a clean, high-contrast light mode.
    * Persistent Settings: Your theme preference is saved locally for a consistent experience.

6. 🎨 Advanced UI/UX Design
    * Glassmorphism: Elegant card layouts with frosted-glass effects and modern neon accents.
    * Smooth Transitions: Powered by CSS variables for seamless theme switching and responsive scaling.
    * Iconic Representation: Dynamic weather icons that change based on current atmospheric conditions.


🛠️ Technologies Used:
----------------------
1. Core Stack
    * HTML5: Semantic structure optimized for data-heavy dashboards.
    * CSS3: Advanced styling using Flexbox, CSS Grid, and custom Keyframe animations.
    * JavaScript (ES6+): Handling complex Async/Await API calls and dynamic DOM rendering.

2. Libraries & APIs
    * OpenWeatherMap API: To fetch real-time weather, forecast, and AQI data.
    * Leaflet.js: For rendering interactive, high-performance geographical maps.
    * LocalStorage API: For managing user preferences, favorites, and history without a database.

3. Design Assets
    * Google Fonts: Using 'Arial' and professional sans-serif fonts for maximum clarity.
    * Font Awesome: Integrated for intuitive weather-related iconography.

📲 Fully Responsive Architecture:
    * Mobile-First Layout: The dashboard is perfectly optimized for tablets and smartphones.
    * Adaptive Grid: Data cards and map elements resize dynamically to fit any screen resolution.
